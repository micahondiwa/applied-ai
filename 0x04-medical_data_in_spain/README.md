# Medical Data in Spain

This project applies a Generative Adversarial Network (GAN) system in generating new images, both by building one and using a pretrained GAN. The images will be a variety of medical images, such as X-rays and MRIs. The project also involves creating a web app using Streamlit to allow users to interact with GAN. 

Summary:

- Creating and training a GAN.
- Using a pre-trained GAN to generate images and data.
- Training a model using synthetic data from a GAN.
- Building a web app using Streamlit.
